Pick & Shiny - a mod for Eslabong (Steam)
==========================================

What it does
  * Shiny chance for YOUR OWN fighters (starters, market, scouting, rewards):
    1 in 2 by default (you can choose 1 in anything). AI teams keep the normal 1 in 5000.
  * Starter picker: on the new-club screen, in Random Mode and Champion Mode, every starting
    fighter gets  < Reroll >  underneath:
      < / >      pick that fighter's class (hold to scroll)
      Reroll     same class, new stats and a new shiny roll; the others stay
      1 / 2 / 3  reroll that slot from the keyboard, Shift+1/2/3 = next class
  * Champion Mode starts with 3 champions (all different) instead of 1 champion + 2 fighters.

Install
  1. Close Eslabong.
  2. Unzip this folder anywhere and double-click PickAndShiny.exe.
     Windows may warn "Windows protected your PC" (the program is not signed by a company):
     click "More info" -> "Run anyway".
  3. The game folder is found through Steam (or use Browse...). Pick your options, click
     "Install / Update" and wait about a minute: it builds the mod for YOUR copy of the game and
     tests it by starting the game invisibly for a few seconds.
  4. Start Eslabong from Steam as usual. The downloaded folder can be deleted afterwards
     (the program keeps a copy in %LOCALAPPDATA%\PickAndShiny).

Game updates
  The mod rebuilds itself when Eslabong updates. Optional but smoother: copy the Steam launch
  option shown in the program into Steam > Eslabong > Properties > General > Launch Options;
  then the update happens before the game starts. Without it, the first start after an update
  shows a short note - just restart the game once.

Uninstall
  Open PickAndShiny.exe (or %LOCALAPPDATA%\PickAndShiny\app\PickAndShiny.exe) > Uninstall.
  If you set the Steam launch option, remove it in Steam before deleting that folder.
  Your saves are never changed by installing or uninstalling. Shinies you already got stay.

Good to know
  * Offline single-player mod. Please don't take modded teams into online modes.
  * This package contains no files from the game: the mod is built on your PC from your own copy.
  * Eslabong's EULA does not allow modifying the game - use at your own risk.
  * Not made by or affiliated with the developers of Eslabong.
  * Log file: %LOCALAPPDATA%\PickAndShiny\auto.log ("Open log folder" in the program).
